# 모던 프론트엔드

> 초보자를 위한 웹 개발 완벽 가이드

이 리포지토리는 **《모던 프론트엔드》** 교재의 모든 예제 코드와 실습 자료를 담고 있습니다.

---

## 📖 목차 및 학습 내용

### 0장 - 준비 단계
- 개발 환경 구축 (VS Code 설치)
- Git 기본 개념 및 설정
- GitHub 저장소 생성 및 연동
- 웹 개발 학습 로드맵

### 1장 - HTML 기초
- HTML 문서 구조 (DOCTYPE, html, head, body)
- 제목, 단락, 텍스트 서식 태그
- 링크(a)와 이미지(img) 태그
- 시맨틱 HTML 소개

### 2장 - HTML 심화
- 폼(form) 요소와 입력 필드
- 테이블(table) 구조와 속성
- 리스트(ul, ol, li) 활용
- 메타 태그와 SEO 기초

### 3장 - CSS 기초
- CSS 선택자 (태그, 클래스, ID)
- 색상, 폰트, 텍스트 스타일
- 상자 모델 (margin, padding, border)
- 단위 (px, em, rem, %)

### 4장 - CSS 레이아웃
- Flexbox 완벽 이해
- Grid 레이아웃 기초
- 반응형 웹 디자인 (Mobile First)
- 미디어 쿼리 활용

### 5장 - CSS 고급
- 애니메이션과 트랜지션
- 그래디언션과 그림자 효과
- 변형(transform) 속성
- 포지셀닝 (static, relative, absolute, fixed)

### 6장 - JavaScript 기초
- 변수, 데이터 타입, 연산자
- 조건문 (if, switch)
- 반복문 (for, while, forEach)
- 함수 정의와 호출

### 7장 - JavaScript 심화
- 객체(Object) 이해하기
- 배열(Array) 메서드
- 스프레드 연산자
- 구조 분해 (Destructuring)

### 8장 - DOM과 이벤트
- DOM 선택 및 조작
- 텍스트 및 HTML 변경
- 클래스 추가/제거
- 이벤트 리스너와 핸들러

### 9장 - 비동기 처리
- Promise 이해하기
- async/await 문법
- fetch API로 데이터 가져오기
- 에러 처리 (try-catch)

### 10장 - 웹 API 활용
- 로컬 스토리지 (localStorage)
- 세션 스토리지
- 타이머 함수 (setTimeout, setInterval)
- 위치 정보 API

### 11장 - 실전 프로젝트
- 날씨 조회 앱 만들기
- TODO 리스트 애플리케이션
- 계산기 프로젝트
- 자동완성 검색 기능

### 12장 - 배포와 최적화
- GitHub Pages로 배포하기
- 성능 최적화 기본 개념
- 번들러 소개 (Webpack, Vite)
- 프로젝트 구조 설계
